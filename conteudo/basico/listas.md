# Listas
+ Lista é uma sequência de objetos;
+ Uma lista é criada usando colchetes;
+ O primeiro elemento possui índice zero;
```
>>> frutas = ["banana", "maçã", "laranja"]
>>> frutas[0]
'banana'
>>> frutas[1]
'maçã'
```
